# Pranic Yoga: SEO guide

## Target long-tail keywords (and where they live)
| Keyword | Page / section |
|---|---|
| free online yoga classes for beginners (India) | Home title, H1, hero text, FAQ |
| online pranayama class for beginners | Class page title and description, FAQ |
| pranayama breathing exercises for beginners | Home "What you'll gain", class text |
| yoga nidra online class for deep relaxation / sleep | Yoga Nidra class page, FAQ |
| mantra meditation online for beginners | Mantra class page, FAQ |
| 41 / 82 / 108 day yoga program online | Membership heading, FAQ |
| live yoga classes on Zoom for beginners | Home description, class pages |

Search volumes were not measured. Check them in Google Search Console (Performance > Queries) after 4 to 8 weeks and
keep the phrases people really use.

## After uploading the files
1. Google Search Console > Sitemaps > add `sitemap.xml` > Submit.
2. Search Console > URL inspection > paste each page address > "Request indexing".
3. When you add a class in data.js, also add its address to sitemap.xml (copy one <url> block) and request indexing.
4. For each new class fill: level, seoTitle (under ~45 characters), seoDesc (~150 characters).
