# Pranic Yoga website

## Host on GitHub Pages
1. Create a repo, upload all files (keep the `images` folder).
2. Settings > Pages > Source: `main` branch, `/ (root)` > Save.
3. Site goes live at `https://<username>.github.io/<repo>/`

## Edit content
Everything is in `data.js`: classes, special classes, memberships (add/edit/delete blocks), instructor, contact.
Paste registration / Join Now links in `registerLink` and `link`.
